# Plan2Model-SU

将户型图与室内设计参考图转化为精细、可编辑、可用于渲染的 SketchUp 室内模型。

## 适用场景

- 根据户型图建立室内空间与家具布局
- 根据参考图深化硬装、柜体、家具、材质、灯光和软装
- 对已有 SketchUp 室内模型进行深化与整理

本 Skill 的目标是交付可继续修改和渲染的 `.skp` 模型，不是只生成效果图。

## 输入要求

必需：

- 户型图或平面布置图
- 设计方向：室内参考图或明确的风格描述

建议同时提供已知尺寸、层高、门窗尺寸和需要重点展示的空间。

如果只提供户型图，Skill 会先询问目标风格和是否有参考图。没有参考图但已明确风格时，会先收集一小组风格统一的参考图；如果授权自由设计，则自行确定风格并收集参考图。在具备参考图，或“明确风格 + 已收集参考图”之前，不会开始精细建模。

## 信息使用原则

| 信息来源 | 决定内容 |
| --- | --- |
| 户型图 | 墙体、房间边界、门窗洞口、动线、家具位置、朝向与尺度 |
| 参考图 | 硬装、柜体、家具造型、材质、色彩、灯光与软装 |
| 合理推断 | 缺失信息；关键假设会被记录 |

当户型图与参考图冲突时，以户型图的结构和布局为准。

## 工作方式

1. 分析户型、尺寸、门窗、固定构件、家具布局和尺度线索。
2. 提炼参考图中的材质、色彩、家具轮廓、灯光和软装语言。
3. 建立墙体、地面、天花、门窗和洞口等空间基础。
4. 先校准家具位置和动线，再完成家具、柜体与装饰细节。
5. 整理材质、贴图、灯具和相机视图，准备渲染。
6. 检查并交付模型、必要贴图、视图、参考来源和关键假设。

## 建模标准

- 独立构件使用 SketchUp Group；重复物体使用 Component。
- 保持真实尺度、人体工学、通行空间和门柜开启逻辑。
- 占位体块只用于布局阶段；最终模型不保留方块式家具。
- 家具应匹配参考图的比例、轮廓和可见构造细节。
- 重点细化近景和可见区域；隐藏面与重复物体适度简化，以兼顾渲染质量与模型效率。
- 保持模型可编辑，避免把核心结构或家具处理为不可修改的扁平内容。

## 完成标准

- 平面与户型图一致，尺寸、门窗、家具位置、朝向和尺度合理。
- 指定空间已完成硬装、家具、灯光和软装细化。
- 无占位物、明显穿模、悬空、反面或不合理碰撞。
- Groups、Components、标签、材质和贴图组织清楚。
- 交付 `.skp` 模型、必要贴图、概览与细节视图，以及关键假设和未解决问题说明。
